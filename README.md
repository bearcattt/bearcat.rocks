# My Bio Site

A personal bio site built with Astro & Tailwind CSS.

## Development

Requires Node.js 22.23.4+

```sh
git clone https://github.com/bearcattt/bearcat.rocks.git
cd bearcat.rocks
pnpm install
pnpm dev
```
